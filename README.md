# BS_Thesis_Repository

## Supplementary Results and Codes

## File Structure
- **Read Me**
- **Code Files** – contains codes for ODE, SSA, and pCA simulations.  
  ODE and pCA were implemented using the Python language, while SSA was implemented using the Julia language.
- **Results** – contains raw data, plots, and animations used in the study.

## Results are sorted based on simulation and data analysis
- **ODE technique** – contains the following folders:
  - **Simulation_CSV** – CSV files of raw results
  - **Time_Series_PNG** – PNG files of the time-series plots

- **SSA technique** – contains the following folders:
  - **Simulation_CSV** – CSV files of raw results
  - **Time_Series_PNG** – PNG files of the time-series plots
  - **Population_distribution_PNG** – PNG files of the population distribution plots for individual time points
  - **Population_distribution_GIF** – GIF files of the population distribution plots

- **pCA technique** – contains the following folders:
  - **Simulation_CSV** – CSV files of raw results
  - **Time_Series_PNG** – PNG files of the time-series plots
  - **Lattice_GIF** – GIF files of the lattice evolution

- **RMSD analysis** – contains PNG files of the RMSD plots
- **FSA analysis** – contains PNG files of the FSA plots
